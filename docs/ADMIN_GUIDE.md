## 1. ภาพรวม 1 นาที

```
แพทย์ต้นทาง ──Google Form──▶ ชีต referrals ──▶ Telegram แจ้งทีม (ฟรี)
      ▲                                              │
      │ อีเมล (รหัสเคส · คำตอบ · ลิงก์ห้องเคส)        ▼
      │                                     dashboard (ตอบ + อาจารย์รับรอง)
      └──── LINE bot ถาม "เคสของฉัน" (reply ฟรี) ◀────┘
```

หลักการที่ระบบยึด (8 ก.ย. 2569):
- **1 เรื่อง = 1 เคส** คำถามใหม่ = ส่งฟอร์มใหม่
- **ไม่มี LINE push** (มีค่าใช้จ่าย) — แจ้งทีมทาง Telegram · แจ้งแพทย์ต้นทางทางอีเมล · LINE bot ตอบเมื่อถูกทักเท่านั้น
- **ทุกคำตอบต้องมีอาจารย์รับรอง** ก่อนส่ง
- ห้องเคส (`/case/<token>`) มีไว้ **แนบเอกสาร/อ่านคำตอบ** ไม่ใช่แชททั่วไป
- **PDPA:** ไม่มีชื่อ/HN ผู้ป่วยในกลุ่ม อีเมล หรือ LINE — อ้างอิงด้วยเลขเคสเท่านั้น (ยกเว้นกลุ่ม fellow เห็นเพศ/อายุ/โรค)

## 3. ทีมภายใน — เข้า dashboard

| ทาง | วิธี | เหมาะกับ |
|---|---|---|
| **Telegram** (แนะนำ) | ในกลุ่ม แตะปุ่ม **📲 เปิด dashboard** ที่ปักหมุด (Mini App) หรือพิมพ์ `/login` รับลิงก์ทาง DM | ทุกคนในกลุ่ม |
| **LINE login** | หน้า `/login` กด "เข้าด้วย LINE" — ผ่านถ้าอยู่ในกลุ่ม LINE ที่ผูกไว้ | คนที่ใช้ LINE |
| รหัสผ่าน | `/login` ด้วยบัญชีใน `DASHBOARD_USERS` | แอดมิน/สำรอง |

Session อยู่ 8 ชั่วโมง

### ตั้งกลุ่ม Telegram (ครั้งเดียว)
สแกน QR 3 กลุ่มที่หน้า **dashboard → กลุ่ม LINE/Telegram** (resident · fellow · แอดมิน) — บอท `hemaSIbot` อยู่ในกลุ่มแล้ว

### ผูกกลุ่ม LINE ของทีมเอง (ไม่ต้องขอ #id)
1. หน้าตั้งค่า → คัดลอก `ผูกกลุ่ม <รหัส>`
2. เชิญบอท LINE OA เข้ากลุ่ม dent/fellow ที่ใช้อยู่ → พิมพ์บรรทัดนั้นในกลุ่ม
3. ใช้ได้ทันที: ถามบอท + LINE login · เอาบอทออกจากกลุ่มหรือพิมพ์ `ยกเลิกผูกกลุ่ม` = สิทธิ์หลุด
(ต้องเปิด "Allow bot to join group chats" ใน LINE OA Manager ก่อน)

## 4. คำสั่งบอท (Telegram / LINE)

พิมพ์ `เมนู` ในกลุ่มเพื่อดูรายการล่าสุด · บอท**ตอบเฉพาะเมื่อถูกถาม** ไม่ส่งเข้ากลุ่มเองยกเว้น digest 10:00 (Telegram)

### ถาม (ทุกกลุ่ม ทั้ง Telegram และ LINE)
| พิมพ์ | ได้อะไร |
|---|---|
| `เคสค้าง` | เคสกลุ่ม 2/3 ที่ยังไม่ตอบ + สถานะ SLA |
| `ข้อความใหม่` | เคสที่แพทย์ต้นทางส่งข้อความ/ไฟล์มา |
| `<ชื่อ resident>` | เคสค้างของตัวเอง + เวรของตัวเอง |
| `นัดวันนี้` · `นัดพรุ่งนี้` · `นัด 15/9` | นัดกลุ่ม 1 (ใส่ปี พ.ศ. ได้ `15/9/69`) |
| `นัด fellow` · `นัด fellow 14` | นัด 7 / 14 วันข้างหน้า |
| `<ชื่อ fellow>` | นัดของตัวเอง |
| `เวรราวด์` (หรือ `เวร` / `chief`) | เวร Chief ประจำวอร์ดตอนนี้ + รอบถัดไป |
| `เมนู` | รายการคำสั่งทั้งหมด |

### ตอบ / มอบหมาย (Telegram)
| พิมพ์ | ผล |
|---|---|
| **ปัด Reply ข้อความแจ้งเคสของบอท แล้วพิมพ์คำตอบ** | ส่งถึงแพทย์ต้นทาง (บันทึกห้องเคส + อีเมล) — ง่ายสุด |
| `ตอบ 0142: ข้อความ` | ระบุเคสด้วยเลข 4 ตัวท้าย (`:` ใส่หรือไม่ก็ได้) |
| `ตอบ HEM-20260910-0142: ข้อความ` | แบบเต็ม |
| `มอบ 0142: ชื่อ` | เปลี่ยน/มอบผู้รับผิดชอบ (ชื่อตามชีต residents) → แจ้งกลุ่มแอดมิน |
| `#ABCD ข้อความ` (กลุ่มแอดมิน) | ตอบตั๋วติดต่อจากแพทย์ต้นทาง — ส่งฟรีเป็น LINE reply ตอนเขาทัก + อีเมลถ้ามี |
| `รหัสผูกกลุ่ม` · `เปลี่ยนรหัสผูกกลุ่ม` (กลุ่มแอดมิน) | ดู/ออกรหัสใหม่ |
| `/login` · `/app` | เข้า dashboard |

### สิ่งที่บอทส่งเองใน Telegram
| เมื่อไร | กลุ่ม | เนื้อหา |
|---|---|---|
| มีเคสกลุ่ม 2/3 ใหม่ | resident | เลขเคส เพศ/อายุ/โรค ผู้รับผิดชอบ รพ. + ปุ่มอ่าน |
| มีนัดกลุ่ม 1 ใหม่/ยกเลิก | fellow | รายละเอียดนัด |
| แพทย์ต้นทางส่งข้อความ/ไฟล์ในห้องเคส | ตามกลุ่มเคส | แจ้งครั้งแรกของชุด (ไฟล์แจ้งทุกครั้ง) |
| ตอบคำปรึกษาแล้ว | ตามกลุ่มเคส | ✅ … ตอบแล้วโดย … (อ. …) |
| แพทย์ต้นทางติดต่อผ่าน LINE | แอดมิน | ตั๋ว `#ABCD` + เบอร์โทรกลับ |
| 10:00 ทุกวันทำการ | resident / fellow / แอดมิน | เคสค้างละเอียด / นัดวันนี้-พรุ่งนี้ / เตือน SLA เหลือง-แดง |

## 7. ซ่อมบำรุง — Repair.gs

รันจาก Apps Script editor: เลือกฟังก์ชัน → **Run** → ดู **Execution log**
ทุกตัวมี **preview** (ไม่เขียน) ก่อน **apply** — รันซ้ำได้ ไม่มีอะไรจะแก้ก็บอกว่าไม่มี

| อาการ | รัน (ตามลำดับ) | ทำอะไร |
|---|---|---|
| อีเมลไม่ส่ง / dashboard 0 เคส / ตรวจโครงสร้างฟ้อง "หัวคอลัมน์ซ้ำ" | `previewRepairDuplicateHeaders()` → `applyRepairDuplicateHeaders()` | ย้ายค่าจากคอลัมน์ซ้ำเข้าคอลัมน์แรก แล้วลบคอลัมน์ซ้ำ |
| เคสมีธง "⚠️ แปลง referral_type ไม่สำเร็จ" / `referral_type` ว่าง | `previewReprocessBrokenRows()` → `applyReprocessBrokenRows()` | เติมกลุ่ม · ส่งอีเมลรหัสที่ค้าง · มอบหมายตามเวร · แจ้งกลุ่ม resident · ล้างธง |
| เคสค้าง "ยังไม่มอบหมาย" ทั้งที่มีเวร | `previewAssignUnassignedCases()` → `applyAssignUnassignedCases()` | มอบตามเวร ณ วันที่ส่ง (วนตามลำดับ) + แจ้งกลุ่มแอดมิน |
| เคสเก่า `referral_type` ว่าง (ไม่ต้องส่งอีเมล) | `previewBackfillReferralTypes()` → `applyBackfillReferralTypes()` | เติมกลุ่มอย่างเดียว |
| หัวคอลัมน์กลายเป็นภาษาไทย | `restoreFormHeaders()` | เขียนหัวคอลัมน์ 1-39 กลับเป็นชื่อระบบ |

**ลำดับที่ถูกต้องเสมอ:** ซ่อมหัวซ้ำ → reprocess → มอบหมาย (reprocess จะปฏิเสธถ้ายังมีหัวซ้ำ)

## 8. ไล่อาการเมื่อพัง

| อาการ | เช็คก่อน | แก้ |
|---|---|---|
| ส่งฟอร์มแล้ว**ไม่มีอีเมล** | Apps Script → Executions ดู `onFormSubmit` ล่าสุด · หน้าตั้งค่า → ตรวจโครงสร้างชีต | หัวซ้ำ → §7 · ไม่มีอีเมลในแถว → แพทย์ไม่ได้กรอก · โควตาอีเมลเต็ม (100/วัน) → รอวันถัดไป |
| dashboard **0 เคส** แต่ Telegram เห็น | banner บน dashboard พิมพ์ท้าย ID ไฟล์ เทียบกับ `whichSheetAmIReading()` | ID ไม่ตรง → แก้ `GOOGLE_SHEET_ID` · ตรงแต่ยัง 0 → หัวซ้ำ §7 |
| เคสขึ้น "ยังไม่มอบหมาย" | `/dashboard/duty` วันนั้นมีเวรไหม | ไม่มีเวร → เติมเวร · มีเวร → `applyAssignUnassignedCases()` |
| บอท Telegram **ไม่ตอบ** | `telegramWebhookInfo()` — `url` ว่างหรือ `pending` สูง | รัน `setTelegramWebhook()` · ถ้า url เป็น `/dev` แก้ `WEB_APP_URL` เป็น `/exec` · Deploy → New version |
| บอทตอบ **"ไม่รู้จักคำสั่ง"** ทั้งที่โค้ดมี | deployment เก่า | Deploy → **New version** (ไม่ใช่แค่ Save) |
| บอท**ตอบซ้ำ**/วนไม่หยุด | Executions `doPost` ถี่ผิดปกติ | webhook ต้องชี้ `<เว็บ>/api/telegram` ไม่ใช่ Apps Script ตรง · `deleteTelegramWebhook()` แล้วตั้งใหม่ |
| LINE bot ในกลุ่ม**เงียบ** | พิมพ์ `#id` ในกลุ่ม — บอกว่าเป็นกลุ่มเจ้าหน้าที่ไหม + เวอร์ชันโค้ดที่ตอบ | ยังไม่ผูก → `ผูกกลุ่ม <รหัส>` · เวอร์ชันเก่า → Deploy |
| LINE login **ไม่ผ่าน** | ชีต `dashboard_logins` แถวล่าสุด | ไม่อยู่ในกลุ่มที่ผูก → เชิญเข้ากลุ่ม/ผูกกลุ่ม |
| ปุ่ม "เปิด dashboard" ใน Telegram **เข้าไม่ได้** | `TELEGRAM_APP_LINK` และ `TELEGRAM_WEBHOOK_SECRET` ตรงกับเว็บไหม | แก้แล้ว Deploy → New version |
| "นัดวันนี้" ไม่เห็นนัด | `debugAppointments()` | สถานะไม่ใช่ Appointment Confirmed หรือวันที่ผิดรูปแบบ |
| ตอบคำปรึกษาแล้ว**อีเมลไม่ถึง** | Executions หา "ส่งอีเมล…ไม่สำเร็จ" | ที่อยู่ผิด/โควตาเต็ม · ส่งสำเนาซ้ำได้จากหน้า review |
| แก้ Google Form แล้วทุกอย่างพัง | ตรวจโครงสร้างชีต | หัวไทย → `restoreFormHeaders()` · หัวซ้ำ → §7 · ป้ายกลุ่มเปลี่ยน → ระบบยึด "กลุ่มที่ N" อยู่แล้ว อย่าเปลี่ยนเลข |
| แอป Telegram ค้าง "connecting" | statusgator.com/services/telegram | Telegram ล่ม ไม่ใช่ระบบเรา (บอทยังรับข้อความ) |

## 9. แก้โค้ดแล้วต้อง deploy อะไร

| แก้ที่ | ต้องทำ |
|---|---|
| Apps Script (ไฟล์ `.gs`) — trigger เวลา, onFormSubmit | **Save** พอ (trigger ใช้โค้ดล่าสุด) |
| Apps Script — webhook (Telegram/LINE), คำสั่งจากเว็บ (`doPost`) | Save → **Deploy → Manage deployments → ✏️ → New version → Deploy** (URL เดิม) |
| เว็บ (`src/`) | `git push` → Cloudflare build อัตโนมัติ |
| Script Properties / config ชีต | มีผลทันที ไม่ต้อง deploy |
| ข้อความปักหมุด Telegram | รัน `pinDashboardButtons()` แล้วปักหมุดข้อความใหม่ |

เช็คว่า deploy ถูกเวอร์ชัน: พิมพ์ `#id` ใน LINE (บอกเวอร์ชันโค้ดที่ตอบ) หรือดู `API_VERSION` ใน `Api.gs`
